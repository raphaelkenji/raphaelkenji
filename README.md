### 🧭 A little about me

I'm a Software Developer and Computer Science graduate from **CEFET/RJ**, interested in what happens beyond the code itself.

I work across backend development, APIs, databases, automation, and observability. I enjoy understanding how systems fit together, making existing software easier to maintain, and improving the workflows that keep development moving.

### 🔭 What I'm exploring

- **Backend engineering**: APIs, integrations, SQL, and system modernization.
- **Infrastructure & automation**: CI/CD, Docker, infrastructure as code, and reusable workflows.
- **Observability & reliability**: metrics, telemetry, dashboards, and understanding what systems are doing.
- **AI-assisted development**: practical automation, engineering guardrails, and more reliable development workflows.
